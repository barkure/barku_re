# Using Bun with Vite and SvelteKit

This project uses `bun` as the package manager and task runner, with standard `vite` and `svelte-kit` scripts defined in `package.json`.

## Review Checklist

- [ ] Run `bun install` after pulling remote changes and before getting started.
- [ ] Run `bun run check` and `bun run build` to validate changes.
- [ ] Use `bun run lint:fix` and `bun run format` when you need automatic lint or formatting fixes.
- [ ] Check `package.json` for any additional scripts that should be run with `bun run <script>`.
